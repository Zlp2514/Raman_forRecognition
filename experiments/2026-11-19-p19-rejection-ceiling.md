# 2026-11-19 · P19 论文图 4：拒识净收益的 1/N 上限

## 目的

论文图 4，也是讨论 4.2 节的支柱。要把一句论断变成一张图：

> **拒识系统的净收益存在 1/N 的结构性上限，且实测曲线永远够不到这条上限。**

## 方法

沿用级联设置（Fisher 加权 + 峰位对齐 + 分类别阈值），对每个（未知类 × 批次折）
只计算一次门控得分与闭集准确率，然后对阈值分位数做**纯查表扫描**
（keep_rate 0.50→1.00，11 档），得到每个操作点的误拒率（FRR）、拒识率（RR）与净收益。

净收益定义：

```
open = c · a · (N−1)/N + r · 1/N          （c=闭集准确率，a=已知接受率，r=未知拒识率）
Δ    = r/N − c · FRR · (N−1)/N            （FRR = 1 − a）
```

盈亏平衡条件：**r ≥ c·(N−1)·FRR**。两条硬推论：

- 完美门控（FRR=0, r=1）的收益上限 Δ = 1/N：细菌 16.7 pt、油脂 12.5 pt；
- 由于 r ≤ 1，**误拒率存在不可逾越的天花板 FRR ≤ 1/(c·(N−1))**：
  油脂为 1/6.3 ≈ 0.159，细菌为 1/4.5 ≈ 0.222。

## 结果

| 数据集 | 可达的最低 FRR | 盈亏平衡所需 FRR | 最优净收益 |
|---|---|---|---|
| 细菌（N=6） | 0.032 | ≤ 0.222 | **−0.41 pt** |
| 油脂（N=8） | 0.268 | ≤ 0.159 | **−5.92 pt** |

![收益上限](../raman_for%20test/02_AI协助_12-22/rejection_ceiling.png)

**左图（权衡曲线）**：实测曲线整体位于盈亏平衡线下方。油脂集的可达最低 FRR（0.268）
已经**超过**盈亏平衡允许的上限（0.159）——在留批次协议下，**油脂集的门控在几何上不可能
净赚**，无论阈值怎么调。

**右图（净收益曲线）**：两条曲线全部位于零线以下，距 1/N 上限（16.7 / 12.5 pt）很远。
细菌集在最松阈值下最接近盈亏平衡（−0.41 pt），但始终没有跨越零线。

## 三个结论

**1. 留批次协议下，拒识门控净收益恒为负。** 这不是"调一下阈值"能解决的：
油脂集的最小可达误拒率（0.268）就超过了盈亏平衡点（0.159），是几何上的不可能。

**2. 细菌集差一点点，但仍然为负（−0.41 pt）。** 它的最小 FRR（0.032）在盈亏平衡
允许范围内，但实测拒识率（0.107）略低于所需（0.144）。
**这意味着如果阈值标定能跨批次稳定，细菌集的级联可能刚好过零**——
这是 P12 遗留问题的定量答案：改进方向存在，但空间极窄。

**3. 1/N 上限（16.7 / 12.5 pt）与实测最优（−0.4 / −5.9 pt）之间的巨大差距，
全部来自误拒率无法压到零。** 完美门控是理论构造；真实门控在跨批次条件下
最少误拒 3%–27% 的已知样本。

## 对论文叙述的意义

3.4 节的定性说法（"级联在留批次下不及纯分类器"）现在有了完整的定量支撑：

> 收益上限 1/N 是算术约束；而实测的门控在留批次下最小误拒 3%–27%，
> 使净收益恒为负。**在设计拒识系统前，应先用式 r ≥ c·(N−1)·FRR 估算盈亏平衡点，
> 再测量门控可达的 FRR——若前者不可达，级联方案应当直接放弃。**

这条判据可以直接写进论文的结论部分，作为给实践者的操作建议。

## 实现说明

开发过程中修了两个 bug，都值得记录：

1. **分位数扫描的聚合错误**：FRR/RR/净收益按"档 × 条目"累积，
   返回时误对**全部值**求同一个均值，导致 11 档输出完全相同。
   修正为 reshape 后按档平均。
2. **库谱双重加权**：库谱在构建时已乘过 Fisher 权重，计算真匹配得分时又乘了一次，
   使阈值整体偏低、扫描退化。修正为只对查询侧加权。

## 局限

- 闭集分类器只见过已知类（与级联设定一致），其准确率低于完整模型；
  若允许"先判库内/库外、再在完整模型上判类"，数字会略好，但结构结论不变。
- 门控实现仍是相关系数族；峰位匹配打分未测。
- 未知类占比固定为 1/N；若实际部署中未知物比例更高（如筛查场景 50%），
  收益上限提高，级联可能转正——**应用场景的先验占比是决定性参数**。
